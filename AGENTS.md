# Работа с конфигурацией

Для установки и переноса end-4 следуй `end4/AGENTS.md`.
Для обновления уже активной конфигурации после clone/pull прочитай
`end4/skills/end4-update-active-config/SKILL.md` и следуй ему. Обновление
должно сохранять настройки текущего компьютера и учитывать установленную
ревизию; обычное копирование снимка установщиком для этого не подходит.

После изменения dotfiles сразу применяй изменения текущей задачи к уже
активной системе по `skills/dotfiles-apply-active/SKILL.md`. Это часть работы,
не требующая отдельного напоминания или повторного подтверждения. Сохраняй
локальные настройки и чужие изменения. Исключение — явная просьба пользователя
не применять конфиги или запрос только анализа.
