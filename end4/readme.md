# Переносимый снимок end-4 для другого компьютера

Репозиторий хранит текущую конфигурацию end-4 для переноса на другой
компьютер: ноутбук, стационарный ПК или систему с другим набором экранов.
Автоматическая полная установка снимка сейчас поддерживается на Arch Linux и
CachyOS. Это ограничение дистрибутива, а не форм-фактора: другие ОС этим
установщиком не поддерживаются.

Снимок включает Hyprland, Quickshell ii, настройки интерфейса, обои,
исполняемый launcher, запись Wayland-сессии и Maple Mono. В Quickshell есть
локальные изменения: календарь с переводами и цветами активностей,
масштабирование недельного графика, горизонтальный свайп, история уведомлений
и отображение использования ресурсов. Цветовая тема обоев генерируется на
целевой системе.

Git-алиасы из активной конфигурации Fish хранятся отдельно в
`home/.config/fish/conf.d/end4-git-aliases.fish`. Установщик копирует только
этот файл в `~/.config/fish/conf.d/`, откуда Fish загружает его автоматически;
остальные файлы конфигурации Fish не заменяются. Алиасы включены в резервную
копию вместе с другими заменяемыми настройками.

Maple Mono используется конфигурацией Quickshell, поэтому файлы TTF и
`LICENSE.txt` находятся в репозитории. Установщик копирует их в
`$XDG_DATA_HOME/fonts/MapleMono` (обычно `~/.local/share/fonts/MapleMono`),
обновляет fontconfig-кэш и проверяет, что семейство видно системе. Файлы шрифта включены неизменёнными вместе с лицензией
SIL Open Font License 1.1; источник указан в `README.txt` рядом со шрифтом.

Не переносятся пароли, ключи, Wi-Fi, браузерные данные, история уведомлений,
календарь, todo, кэш и другие пользовательские данные. Пакетные списки в
`packages/` служат для справки и не устанавливаются целиком. Maple Mono —
отдельное исключение: конфиги напрямую ссылаются на это семейство.
Настройки сторонних приложений намеренно не копируются.

Исходники Voice Assistance включены в
`home/.config/quickshell/ii/scripts/voice-assistant` и устанавливаются
вместе с Quickshell. Служба использует эту встроенную копию. Подготовка Bun,
Vosk и локальных настроек описана в
[README помощника](home/.config/quickshell/ii/scripts/voice-assistant/README.md).

## Полная установка на Arch Linux или CachyOS

Полный режим вызывает закреплённый установщик end-4, устанавливает его
основные зависимости через `pacman` и `yay`, копирует снимок и регистрирует
сессию **Hyprland (end-4 portable)** для экрана входа. Нужны сеть, `pacman`,
`sudo` с правами для текущего пользователя, `python3`, `git` и обычный
интерактивный терминал. Если Python или Git отсутствует, сначала поставьте
недостающие пакеты из терминала:

    sudo pacman -S --needed python git

Затем запустите установщик от обычного пользователя, не от root:

    ./install.sh --monitor-scale 1

Масштаб выбирается по основному экрану целевого компьютера; сохраните уже
рабочее значение Hyprland, если оно подходит. При наличии размеров EDID можно
оценить начальный scale как DPI / 110, округлённый до ближайшей четверти.
Установщик принимает значения от `0.5` до `4.0` и заменяет desktop-привязки к
DP-1/DP-2 автоопределением подключённых экранов.

`--configs-only` предназначен для компьютера, где end-4 уже установлен. Он
копирует конфиги, Maple Mono и launcher, но не ставит пакеты и не регистрирует
системную Wayland-сессию. Этот режим не подходит для первой установки на
чистой системе.

Установщик регистрирует сессию в
`/usr/share/wayland-sessions/end4-portable.desktop`, но не устанавливает и не
включает дисплейный менеджер. AI-агент должен проверить существующий менеджер
входа и сохранить его. Если менеджера нет, включите SDDM в план. После установки snapshot выполните
`sudo pacman -S --needed sddm` и `sudo systemctl enable --now sddm`. Затем на
экране входа выберите **Hyprland (end-4 portable)**.

Полный режим задаёт вопросы upstream setup и может запросить пароль sudo.
Установщик сам не устанавливает Python или Git до старта. Наличие сети и
пакетов на целевой системе проверяется при реальной установке; dry-run этого
не подтверждает.

## Перенос на другую ОС

Полный автоматический режим этого репозитория требует Arch Linux или CachyOS.
На другой ОС он не запускает пакетную установку. Конфиги можно адаптировать
вручную после установки совместимых Hyprland, Quickshell и end-4-компонентов,
но такой путь не проверен как готовый сценарий. Не запускайте `--configs-only`,
если end-4 не установлен.

## Инструкции AI-агенту

Перед переносом попросите AI прочитать `AGENTS.md`,
`skills/end4-transfer-setup/SKILL.md` и `INSTALL_PROMPT.md`. Не предполагайте,
что целевая система — ноутбук: инвентаризация определит тип машины и экраны.
Поле `laptop_likely` в hardware-профиле — только наблюдение о наличии батареи
или внутренней панели. Профиль содержит модель CPU/GPU, память, подключённые
экраны, батарею, тачпад и свободное место; не запускайте диагностику через sudo
и не публикуйте JSON наружу.

Инвентаризация и план без изменений:

    ./install.sh --inventory
    ./install.sh --dry-run --monitor-scale 1

Все заменяемые пользовательские файлы и шрифты резервируются в
`~/.local/state/end4-transfer-backups/`. После полной установки выйдите из
сеанса и на экране входа выберите Wayland-сессию снимка.
