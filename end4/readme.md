# Перенос end-4 на ноутбук

В репозитории сохранён снимок пользовательских настроек CachyOS/end-4, включая
Hyprland, Quickshell ii, параметры интерфейса, текущие обои и списки
установленных вручную пакетов. Снимок обновлён 13 октября 2026 года.

В Quickshell включены сделанные локально функции: история уведомлений,
календарь с переводами, цветами активностей, масштабированием недельного
графика и исправленным горизонтальным свайпом. Настройки генерации цветов
обоев остаются динамическими, чтобы тема создалась на новом устройстве.

Не переносятся записи истории уведомлений, календарь, todo, кэш, пароли,
ключи, Wi-Fi, браузеры и другие пользовательские данные. На ноутбуке история
уведомлений и календарь начнутся отдельно. Списки Arch/AUR в packages/
даны для справки и не устанавливаются целиком: там есть приложения, которые
могут не подойти ноутбуку.

## Установка

Клонируйте репозиторий и перейдите в каталог end4:

    git clone https://github.com/injurka/dotfiles.git
    cd dotfiles/end4

Затем попросите AI-агента прочитать
AGENTS.md, skills/end4-laptop-setup/SKILL.md и INSTALL_PROMPT.md.
Профиль оборудования содержит только модель процессора и видеокарты, объём
памяти, сведения о подключённых экранах, наличии батареи/тачпада и свободное
место. Он не записывает имя пользователя, имя компьютера, серийные номера,
сетевые адреса или данные приложений.

Вручную посмотреть профиль:

    ./install.sh --inventory

Посмотреть план установки без изменений:

    ./install.sh --dry-run --monitor-scale 1.5

При установке полного end-4 на Arch Linux или CachyOS:

    ./install.sh --monitor-scale 1.5

Если end-4 уже установлен:

    ./install.sh --configs-only --monitor-scale 1.5

Значение масштаба выбирается по экрану ноутбука. Если есть физические размеры
EDID, можно оценить DPI и начать с DPI / 110, округлённого до четверти
(например, 1.5 или 2). Сначала сохраняйте уже рабочее значение из Hyprland,
если оно подходит. Установщик принимает scale от 0.5 до 4.0.

Установщик делает резервную копию заменяемых настроек в
~/.local/state/end4-transfer-backups/, берёт закреплённую ревизию форка
end-4 и адаптирует мониторы, убирая desktop-привязки к DP-1/DP-2. Для полного
установщика end-4 могут понадобиться интерактивные ответы и пароль sudo.
После установки выйдите из сеанса и войдите снова.

Установка проверялась во временном каталоге HOME. Реальный перенос на ноутбук
ещё не выполнялся.
