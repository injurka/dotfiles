# Перенос end-4 на ноутбук

Снимок текущего рабочего стола от 13 октября 2026 года. В `home/` лежат
Hyprland, Quickshell `ii`, настройки интерфейса и шесть используемых обоев.
Списки вручную установленных пакетов Arch/AUR находятся в `packages/` для
справки; установщик их целиком не применяет, поскольку там есть программы,
не относящиеся к end-4. Не включены пароли, ключи, Wi-Fi, браузеры, приложения
и пользовательские данные (в том числе записи календаря из `agenda.json`).

На ноутбуке с Arch Linux/CachyOS:

```bash
git clone https://github.com/injurka/dotfiles.git
cd dotfiles/end4
./install.sh
```

Скрипт берёт сохранённую ревизию форка end-4 и запускает его штатный установщик
(у него есть интерактивные вопросы),
затем переносит этот снимок. Имеющиеся конфиги ноутбука сначала копируются в
`~/.local/state/end4-transfer-backups/`. Старый путь `/home/injurka` заменяется
на домашнюю папку пользователя ноутбука. Настройки двух настольных мониторов
заменяются на автоопределение экрана, а переключатели HDR/разрешения для них
отключаются. После установки выйдите из сеанса и войдите снова.

Если end-4 уже установлен, применить только снимок:

```bash
./install.sh --configs-only
```

Исходные параметры `DP-1/DP-2` сохранены в `home/.config/hypr`.
Привязка `Super+Shift+I` обращается к отдельному проекту
`~/my/interview-hypr-assistant`; она заработает после установки этого проекта.
Обои переносятся, но пути к личным папкам для снимков экрана и видео следует
проверить на ноутбуке. Для другой системы или аппаратуры состав пакетов и
настройки служб могут потребовать ручной правки.
