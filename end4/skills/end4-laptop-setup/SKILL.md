# Установка end-4 на этот компьютер

Следуй этому навыку, когда пользователь просит загрузить, установить или
адаптировать end4/ на текущем компьютере. Пользовательское сообщение
«установи end-4 на этот ноутбук» разрешает запуск установки и запись файлов.

## 1. Инвентаризация

Запускай команды от обычного пользователя, не через sudo:

    ./install.sh --inventory
    ./install.sh --dry-run

Инвентаризация не записывает аппаратный профиль на диск и не выводит
пользователя, имя компьютера, серийные номера, MAC/IP-адреса, Wi-Fi,
браузерные данные или содержимое пользовательских файлов. Не дополняй её
чтением таких данных.

Проверь поддержку дистрибутива и выбери режим:

- Arch Linux/CachyOS и end-4 ещё нет: полный режим.
- end-4 уже установлен: только перенос конфигураций через --configs-only.
- Другая система: не запускай полный upstream-установщик; объясни ограничение
  и предложи только безопасный план переноса отдельных совместимых файлов.

## 2. Настройка экрана

Сначала сохраняй уже применённый Hyprland scale, если он подходит ноутбуку.
Если значение неизвестно, используй физические размеры дисплея и активный
режим:

    dpi_x = width_px * 25.4 / width_mm
    dpi_y = height_px * 25.4 / height_mm
    scale = clamp(round((mean(dpi_x, dpi_y) / 110) * 4) / 4, 1, 2.5)

Это начальное значение, а не гарантия идеального размера интерфейса. Если
EDID не сообщает физические размеры, не делай вид, что разрешение показывает
физический DPI: выбери 1.0 либо текущий рабочий scale и сообщи пользователю,
что значение можно изменить позже.

Для eDP/DSI предпочитай режим ноутбучной панели. Если при установке
подключены экраны с заметно разной плотностью пикселей, укажи это в плане:
этот снимок создаёт единое правило scale, а смешанным дисплеям могут
понадобиться отдельные правила Hyprland. Не подменяй их молча одним
предполагаемым значением.

Учитывай остальные поля профиля при выборе параметров upstream-установщика:
используй установленный пакетный менеджер и дистрибутив, не ставь вручную
драйвер GPU, при наличии тачпада сохраняй универсальные настройки ввода,
а объём памяти и свободное место используй для оценки необязательных служб и
пакетов. При наличии батареи проверь idle/power-настройки снимка и не
переноси desktop-only поведение без проверки. Не меняй пользовательские
предпочтения питания и ввода по предположению.

## 3. Установка

Покажи краткий план: дистрибутив, выбранный экран, scale и полный или
configs-only режим. Затем запусти dry-run с тем же scale.

Полная установка:

    ./install.sh --monitor-scale SCALE

Только перенос настроек:

    ./install.sh --configs-only --monitor-scale SCALE

Установщик закрепляет ревизию форка end-4, создаёт резервные копии и меняет
конфиги. При интерактивных вопросах upstream-установщика выбирай только
необходимые для текущего компьютера параметры. Пароль sudo не запрашивай в
чате; попроси пользователя ввести его в локальном терминале, если система
потребует пароль.

## 4. Проверка

После завершения проверь, что:

- ~/.config/hypr/monitors.lua использует выбранный scale и предпочитаемый
  доступный экран;
- нет привязок рабочих столов к отсутствующим DP-1/DP-2;
- Hyprland сообщает список ошибок конфигурации;
- Quickshell ii загружается, а новые строки переводов и история уведомлений
  находятся в установленном каталоге;
- пользовательские agenda.json, todo и история уведомлений не были заменены
  файлами из снимка.

Если проверка требует выхода из графического сеанса, попроси пользователя
перезайти и отдели статическую проверку от подтверждения работы на экране.
