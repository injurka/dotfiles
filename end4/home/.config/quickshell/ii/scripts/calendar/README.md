# Рабочий календарь Outlook / Exchange

В заголовке календаря доступны «Личный», «Рабочий», «Все календари».
В общем режиме встречи объединяются в одном дневном и недельном расписании;
пересечения получают отдельные колонки. Личные события остаются в agenda.json.
На недельном таймлайне наведение или нажатие открывает popover с кратким
описанием, кнопкой подключения к созвону и переходом «Подробнее». В дневном
списке нажатие сразу открывает полное описание.
Рабочие встречи доступны только для чтения; карточка показывает описание встречи,
место и кнопки для ссылок из описания, места и поля URL. Кнопка «Открыть Outlook»
позволяет перейти в OWA. HTML-описания преобразуются в обычный текст.
Добавление в режиме «Все» создаёт личное событие, в режиме «Рабочий» открывает OWA.

## Зависимости на текущем компьютере

Установите один раз в отдельное Python-окружение (не входит в снимок):

```bash
python3 -m venv "${XDG_DATA_HOME:-$HOME/.local/share}/ii-calendar/venv"
"${XDG_DATA_HOME:-$HOME/.local/share}/ii-calendar/venv/bin/pip" install -r \
  ~/.config/quickshell/ii/scripts/calendar/requirements.txt
```

Без окружения помощник использует системный python3; библиотеки из requirements.txt
должны быть доступны этому интерпретатору. При отсутствии библиотек подключение
покажет ошибку и сохранит прежние данные.

## Подключение

1. Откройте https://mail.prosebya.ru/owa/#path=/calendar и войдите самостоятельно.
2. В параметрах календаря найдите «Опубликовать календарь» (в новых версиях:
   «Календарь → Общие календари»). Пункт зависит от версии Exchange и политики
   организации. Публикация делает данные доступными обладателям ссылки; выберите
   допустимый уровень подробностей. Если публикация запрещена, потребуется
   согласованный с администратором способ доступа Exchange/EWS; он пока не реализован.
3. Для описаний и ссылок выберите «Полные сведения» и сохраните публикацию.
   Если подписка уже подключена, нажмите «Обновить» в настройках виджета.
4. Скопируйте **ICS**, а не HTML и не адрес страницы OWA.
5. В настройках Quickshell-календаря вставьте ссылку и нажмите «Подключить».
   Запись подписки происходит после первой успешной загрузки.

Не отправляйте секретную ссылку третьим лицам. Помощник загружает её напрямую
с сервера по HTTPS; ссылка передаётся процессу через stdin, не через аргументы.
Ссылка и кэш лежат в `${XDG_STATE_HOME:-~/.local/state}/ii/work-calendar/`
в файлах с правами 0600 и не входят в репозиторий/экспорт личного календаря.
«Отключить» удаляет локальную подписку и кэш; публикация в Outlook отключается
отдельно в OWA.

Обновление происходит при запуске и каждые 15 минут. Загружается период от
90 дней назад до 366 дней вперёд; за его пределами показывается предупреждение.
Поддерживаются повторения, исключения и переносы встреч, UTC/TZID, события
на весь день и события через полночь. Время отображается в часовом поясе компьютера.
При ошибке сети остаётся последний успешный кэш и отображается ошибка.
В этой версии поддерживается одна рабочая подписка ICS.

Документация Microsoft:
https://support.microsoft.com/en-us/outlook/share-your-calendar-in-outlook-on-the-web

В настройках подключения явно показаны статус «Подключён», число загруженных
событий и время последнего обновления. Обновление и переход в Outlook доступны справа от статуса.
Замена ссылки и отключение находятся в меню «⋮».
При ошибке обновления статус сообщает об ошибке и сохраняет доступ к кэшу.

## Размер окна

Календарь — обычное плавающее окно Hyprland. `Super + правая кнопка мыши`
меняет размер, `Super + левая кнопка мыши` перемещает окно. Отдельный уголок
ресайза не используется. Правило окна задаётся по точному заголовку
`Calendar — end4` в `~/.config/hypr/custom/rules.lua`, загружаемом end4.lua.

Минимум — прежний размер: 560×880 для дня и страниц настроек/описания,
1040×880 для недели. На небольшом экране ограничения учитывают размер экрана.
Ширина дня и недели сохраняется отдельно, высота общая; запись происходит
через 400 мс после изменения размера и при закрытии. Максимизация и fullscreen
не подменяют сохранённый обычный размер. Настройки хранятся в
`${XDG_STATE_HOME:-~/.local/state}/user/calendar-window.json`.
«Сбросить размер окна» возвращает значения по умолчанию. Календарь закрывается
кнопкой, Escape или стандартным сочетанием Hyprland для закрытия окна.

В полном описании URL отображаются короткими кликабельными ссылками с сохранением
полного адреса перехода. «Открыть Outlook» и «Присоединиться к встрече» находятся
в закреплённой нижней панели; прокручивается только содержимое встречи.

Настройки собраны в компактные группы с ограничением ширины содержимого:
отображение, шаблоны и резервная копия, управление личными данными.
Видимость распорядка меняется переключателем, импорт/экспорт — короткими
кнопками справа. Восстановление дня и удаление находятся в раскрываемой группе;
удаление сохраняет явное подтверждение. Экспорт личного расписания включён
в переносимый исходник и не содержит рабочую подписку.

## Описания личных активностей

При создании и редактировании личной активности доступно многострочное поле
«Описание». Оно сохраняется для разовых событий, всего распорядка или отдельного
дня серии. Старые события без описания продолжают работать. Нажатие открывает
единый экран описания, где для личных событий есть кнопка редактирования.
Ссылки отображаются в форматированном виде и доступны в недельном popover.
Описания включены в JSON-экспорт и могут задаваться в импортируемых шаблонах.

В дневном списке «All» пересекающиеся по времени активности объединяются
в общую карточку с диапазоном времени. Внутри каждая активность остаётся
отдельной строкой с собственным временем, источником и переходом в описание.
Соседние события, где одно заканчивается ровно в момент начала другого,
не объединяются. В «Personal» и «Work» и на недельном таймлайне вид не меняется.
