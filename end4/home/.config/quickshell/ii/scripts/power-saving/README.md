# Энергосбережение ноутбука

В классической панели кнопка с листом видна при наличии системной батареи
(батареи мыши/UPS не учитываются). ЛКМ переключает режим, ПКМ открывает
настройки. Кнопка блокируется на время операции; ошибки видны в подсказке и
диалоге. Все действия независимы, частичный отказ не блокирует остальные.

По умолчанию: профиль `power-saver`, яркость не выше 35%, отключение анимаций
и размытия Hyprland. Частота и автоматика изначально выключены. Настройки
применяются при следующем включении режима. Яркость никогда не повышается.
Частота выбирается из объявленных монитором режимов с тем же разрешением:
максимальная доступная не выше заданного предела. Если такого режима нет,
контроллер сообщает об этом. Изменение частоты касается только eDP/LVDS/DSI.

Необходимы Python 3 и Lua-версия Hyprland из этого снимка. Для профиля нужны
`powerprofilesctl` и работающий power-profiles-daemon либо совместимый
провайдер; для подсветки — `brightnessctl` с правами пользователя на устройство
из `/sys/class/backlight`. Контроллер не использует sudo, не устанавливает
пакеты и не переключает службы. Недоступные действия отмечаются в диалоге;
их сохранённые настройки не удаляются. Wi-Fi, Bluetooth и приложения не
выключаются.

Настройки: `$XDG_CONFIG_HOME/illogical-impulse/power-saving.json`.
Журнал восстановления: `$XDG_STATE_HOME/end4-power-saving/state.json`.
При незаданных XDG используются `~/.config` и `~/.local/state`. Файлы пишутся
атомарно с режимом 0600, параллельные процессы сериализуются через flock.
Значения сохраняются до изменения оборудования. При выключении контроллер
возвращает только собственные изменения; более позднее ручное изменение
имеет приоритет. При отказе восстановления журнал сохраняется для повторной
попытки (ещё одно нажатие). Поддерживается перезапуск оболочки в том же сеансе;
данные другого входа в Hyprland не восстанавливаются. Удаление журнала во
время работы режима лишает возможности восстановления исходных значений.
Перезагрузка конфига Hyprland или другая программа могут отменить временные
настройки; контроллер не навязывает их повторно.

Автоматика проверяет питание каждые 15 секунд, пока работает оболочка.
Она реагирует только на переход подключено/отключено, а не на запуск оболочки.
Ручной выбор действует до следующего перехода. Автовключение и восстановление
при подключении зарядки настраиваются отдельно.

Изменения частоты сохраняют текущую геометрию и transform. В Lua Hyprland
поля существующего правила с тем же именем выхода объединяются:
[реализация hl.monitor](https://github.com/hyprwm/Hyprland/blob/main/src/config/lua/bindings/LuaBindingsConfigRules.cpp).
Сложные конфигурации HDR/ICC с правилами только по `desc:` требуют проверки
на целевом ноутбуке перед использованием изменения частоты.

Проверка без оборудования:

```sh
python3 test_controller.py
```

CLI: `python3 controller.py status`, `toggle`, `tick` и
`configure '{"hz":60,"refresh":true}'`. Для безопасной проверки только чтения
используйте `status`. CLI и интерфейс используют один и тот же журнал.
