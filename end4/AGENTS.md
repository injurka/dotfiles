# Инструкции для AI-агента

Если пользователь просит установить этот снимок на текущий компьютер:

1. Прочитай readme.md и skills/end4-laptop-setup/SKILL.md.
2. Запусти ./install.sh --inventory от обычного пользователя и используй
   полученный JSON только локально. Не запускай диагностику через sudo.
3. Проверь дистрибутив, дисплеи, физический размер экрана, текущий scale,
   GPU, батарею, тачпад и свободное место. Для дисплея с известным размером
   рассчитай начальный scale по правилам навыка; если текущий scale подходит,
   сохрани его.
4. Перед изменением покажи короткий план с выбранным scale и режимом установки.
   Если пользователь явно попросил установить, продолжай без повторного запроса
   разрешения на обычные действия установщика.
5. Перед полной установкой убедись, что система Arch Linux или CachyOS.
   Не добавляй вручную драйверы GPU и не запускай пакетную установку на другой
   системе. Установщик end-4 может запросить пароль sudo и выбор служб.
6. Запусти ./install.sh --dry-run с выбранными параметрами, затем выполни
   ./install.sh --monitor-scale SCALE; если end-4 уже установлен, добавь
   --configs-only.
7. Конфиги пользователя резервируются в
   ~/.local/state/end4-transfer-backups/. Не копируй секреты, app state,
   историю уведомлений, agenda/todo данные или пользовательские файлы в Git.
8. После установки проверь синтаксис затронутых конфигов, наличие монитора,
   ошибки Hyprland и запуск Quickshell. Не называй проверку временного HOME
   проверкой реального ноутбука.
