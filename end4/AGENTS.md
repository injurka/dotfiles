# Инструкции для AI-агента

Если пользователь просит перенести или установить этот снимок на другой
компьютер:

1. Прочитай `readme.md`, `skills/end4-transfer-setup/SKILL.md` и
   `INSTALL_PROMPT.md`.
2. Определи фактическую ОС через `/etc/os-release`. Запусти
   `./install.sh --inventory` от обычного пользователя; используй JSON только
   локально, не через sudo и не публикуй его.
3. Определи форм-фактор и экраны целевой машины, текущий scale, GPU, батарею,
   тачпад и свободное место. Не предполагай ноутбук: снимок рассчитан также на
   стационарные компьютеры и разные мониторы. Если текущий scale подходит,
   сохрани его; иначе подбери scale по основному экрану и правилам навыка.
4. Полный автоматический режим поддерживает Arch Linux/CachyOS. Для чистой
   системы проверь `python3`, `git`, `pacman`, `sudo`, сеть и интерактивный
   терминал. Если Python или Git отсутствует, установи недостающие пакеты:
   `sudo pacman -S --needed python git`. Запускай `install.sh` обычным
   пользователем с sudo-доступом, не от root и не из фонового процесса.
5. Если целевая ОС другая, не запускай полный `install.sh` и не обещай
   автоматическую установку. Сначала проверь совместимость компонентов; этот
   snapshot не проверен для других дистрибутивов. `--configs-only` применим
   только если end-4 уже установлен.
6. Проверь дисплейный менеджер и состояние службы. Сохрани уже настроенный
   менеджер. Если его нет, включи SDDM в план; после установки snapshot выполни
   `sudo pacman -S --needed sddm` и `sudo systemctl enable --now sddm`. Не
   заменяй существующий работающий менеджер входа.
7. Покажи короткий план с ОС, экранами, scale, режимом и дисплейным менеджером.
   При явной просьбе об установке продолжай после плана без повторного запроса
   разрешения на обычные действия этой установки.
8. Запусти `./install.sh --dry-run --monitor-scale SCALE`. На чистом Arch/CachyOS
   используй полный режим `./install.sh --monitor-scale SCALE`. Он запускает
   закреплённый upstream setup, копирует пользовательский снимок, Maple Mono и
   launcher, затем регистрирует `/usr/share/wayland-sessions/end4-portable.desktop`.
   Установщик не включает дисплейный менеджер автоматически.
9. Подтверди установку Maple Mono через `fc-match 'Maple Mono'`. Не копируй
   пароли, ключи, Wi-Fi, браузеры, историю уведомлений, календарь, todo, кэш
   или другие пользовательские данные. Списки `packages/` справочные и не
   должны устанавливаться целиком.
10. После установки проверь права launcher, запись сессии, синтаксис конфигов,
    ошибки Hyprland, Quickshell и шрифт. Отдельно укажи, что проверено
    статически или во временном HOME, а что требует входа в графический сеанс
    на целевом компьютере.
