# Запрос для AI-агента

Установи этот снимок end-4 на текущий ноутбук. Сначала прочитай
AGENTS.md, skills/end4-laptop-setup/SKILL.md и readme.md. Выполни
локальную инвентаризацию, подбери scale по экрану и текущим настройкам,
покажи короткий план, запусти dry-run и затем выполни установку подходящим
режимом. Сохрани резервную копию существующих настроек, не переноси секреты,
историю уведомлений, календарь и todo с другого компьютера. После установки
проверь конфиги и сообщи, что проверено статически, а что требует повторного
входа в сеанс.
